🔧 OCR API Kurulum Rehberi

Otomatik ölçü tanıma için aşağıdaki ücretsiz OCR servislerinden birini seçin

1. OCR.space API ÜCRETSİZ ÖNERİLEN

Neden OCR.space?
  • ✅ Aylık 25,000 istek tamamen ücretsiz
  • ✅ Kayıt olur olmaz hemen API key alırsınız (30 saniye)
  • ✅ Kredi kartı bilgisi gerektirmez
  • ✅ Teknik resimler için optimize edilmiş
  • ✅ Türkçe karakter desteği

📋 Kurulum Adımları (3 Dakika)

  1. ocr.space/ocrapi adresine gidin
  2. "Register for Free API Key" butonuna tıklayın
  3. Email adresinizi girin ve "Register" yapın
  4. Email'inize gelen API Key'i kopyalayın
  5. Aşağıdaki dosyayı açın ve API Key'i yapıştırın:
// app.js dosyasının 8. satırını düzenleyin:

apiKey: 'K87899142388957', // Bu DEMO KEY - SİLİN
apiKey: 'BURAYA_API_KEYINIZI_YAPIŞTIRIN',
🚀 ŞİMDİ API KEY AL (Ücretsiz)

2. Google Cloud Vision API SINIRLI ÜCRETSİZ

Özellikler:
  • ✅ Aylık 1,000 istek ücretsiz
  • ✅ En yüksek doğruluk oranı (%98+)
  • ❌ Kredi kartı bilgisi gerekli (ücretsiz kotada ücret kesilmez)
  • ❌ Google Cloud hesabı gerekli (karmaşık kurulum)

📋 Kurulum Adımları (15 Dakika)

  1. Google Cloud Console'a gidin
  2. Yeni proje oluşturun
  3. "Vision API"'yi etkinleştirin
  4. "Credentials" > "Create API Key" ile key alın
  5. app.js dosyasında Google ayarlarını yapın
// app.js dosyasında (14-18. satırlar):

google: {
  enabled: true, // false'u true yapın
  apiKey: 'BURAYA_GOOGLE_API_KEY',
},
Google Cloud Console'a Git

3. Mathpix API SINIRLI ÜCRETSİZ

Teknik Resim Uzmanı:
  • ✅ Aylık 1,000 istek ücretsiz
  • ✅ Ø, ±, °, R gibi sembolleri mükemmel tanır
  • ✅ Matematik formülleri destekler
  • ❌ Kayıt formu doldurmanız gerekir

📋 Kurulum Adımları (10 Dakika)

  1. mathpix.com/ocr adresine gidin
  2. "Try for Free" ile kayıt olun
  3. Dashboard'dan APP_ID ve APP_KEY alın
  4. app.js dosyasında Mathpix ayarlarını yapın
// app.js dosyasında (21-26. satırlar):

mathpix: {
  enabled: true,
  appId: 'BURAYA_APP_ID',
  appKey: 'BURAYA_APP_KEY',
},
Mathpix'e Git
