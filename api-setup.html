🔵 OCR.space API Devre Dışı

Ücretsiz: Ayda 25,000 istek

📝 Nasıl API Anahtarı Alınır?

  • 1. OCR.space sitesine gidin
  • 2. "Register for free API key" butonuna tıklayın
  • 3. Email adresinizi girin
  • 4. Gelen maildeki API anahtarını kopyalayıp buraya yapıştırın

🟡 Google Cloud Vision API Devre Dışı

Aylık ilk 1000 istek ücretsiz, sonrası $1.50/1000 istek

📝 Nasıl API Anahtarı Alınır?

  • 1. Google Cloud Console'a gidin
  • 2. Yeni proje oluşturun
  • 3. "APIs & Services" > "Enable APIs" > "Cloud Vision API"
  • 4. "Credentials" > "Create Credentials" > "API key"
